# 비즈니스 모델 정의

## 1. 모델 요약

이 서비스는 SW 수요 기업의 탐색 비용을 줄이고, 지역 SW 공급 기업에는 조건이 맞는 상담 기회를 제공하며, 운영 기관에는 연결 성과를 측정할 수 있는 채널을 제공합니다.

초기 BM은 매출 극대화보다 **검증 가능한 매칭 성과**에 초점을 둡니다. 수요와 공급의 품질이 확인된 뒤 유료 모델을 단계적으로 검토합니다.

## 2. 이해관계자별 가치

| 이해관계자 | 해결할 일 | 제공 가치 | 기대 행동 |
|---|---|---|---|
| 수요 기업 | 적합한 SW 파트너 탐색 | 사례 기반 비교, 신뢰 근거, 간단한 상담 신청 | 상담 요청 |
| 공급 기업 | 유효한 영업 기회 확보 | 역량과 사례 노출, 적합 리드 연결 | 정보 제공 및 상담 대응 |
| 운영 기관 | 사업 성과 창출과 보고 | 유입부터 연결까지의 측정 데이터 | 품질 관리와 후속 조정 |
| 협력 파트너 | 공동 사업 기회 발굴 | 검증된 네트워크와 수요 신호 | 공동 프로그램 참여 |

## 3. Business Model Canvas

| 영역 | 초기 정의 |
|---|---|
| 고객 세그먼트 | SW 도입 수요 기업, 지역 SW 공급 기업, 사업 운영 기관 |
| 가치 제안 | 문제에 맞는 SW 역량을 사례로 이해하고 빠르게 연결 |
| 채널 | 랜딩 페이지, 검색, 기관 캠페인, 행사, 파트너 추천 |
| 고객 관계 | 셀프 탐색 후 운영자 기반 상담·매칭 |
| 핵심 활동 | 콘텐츠 검수, 사례 큐레이션, 상담 접수, 매칭, 성과 추적 |
| 핵심 자원 | 기업·사례 데이터, 운영 네트워크, 브랜드 신뢰, 분석 데이터 |
| 핵심 파트너 | 지역 SW 기업, 산업별 협회, 지원기관, 전문 컨설턴트 |
| 비용 구조 | 기획·개발, 콘텐츠 제작, 캠페인, 상담 운영, 데이터 관리 |
| 수익원 | 초기에는 사업 예산, 이후 유료 노출·검증·성공 기반 모델 검토 |

## 4. 수익 모델 가설

수익 모델은 리드 품질과 이해관계자 신뢰를 훼손하지 않는 순서로 검증합니다.

| ID | 모델 | 지불 주체 | 제공 단위 | 검증할 위험 |
|---|---|---|---|---|
| BM-001 | 기관 운영형 | 운영·지원 기관 | 연간 구축 및 운영 | 예산 종료 후 지속 가능성 |
| BM-002 | 검증 프로필형 | 공급 기업 | 검수된 기업·사례 프로필 | 유료 노출이 신뢰를 훼손할 가능성 |
| BM-003 | 캠페인형 | 공급 기업 또는 파트너 | 산업별 공동 캠페인 | 리드 품질과 비용 대비 효과 |
| BM-004 | 성과형 | 공급 기업 | 유효 상담 또는 계약 성과 | 성과 귀속과 추적의 어려움 |

### 권장 검증 순서

1. `BM-001`로 운영과 수요를 검증합니다.
2. 유효 리드 기준이 안정되면 `BM-002` 또는 `BM-003`을 소규모로 시험합니다.
3. 계약 추적과 이해관계자 합의가 갖춰진 뒤에만 `BM-004`를 검토합니다.

## 5. 핵심 단위 경제성

아래 값은 실제 데이터를 입력할 수 있도록 남겨 둔 계산 구조입니다.

```text
유효 리드당 비용(CPL) = 총 획득 비용 / 유효 리드 수
매칭당 비용           = 총 운영 비용 / 실제 매칭 수
리드→매칭 전환율      = 실제 매칭 수 / 유효 리드 수
매칭→계약 전환율      = 확인된 계약 수 / 실제 매칭 수
공급자 유지율         = 다음 기간 재참여 공급자 / 직전 기간 참여 공급자
```

## 6. 운영 퍼널

```text
방문 → 관심 콘텐츠 확인 → CTA 클릭 → 상담 신청
     → 유효성 검토 → 공급자 매칭 → 상담 진행 → 성과 확인
```

각 단계에는 날짜, 유입 경로, 담당자, 상태 변경 사유를 남겨야 합니다. MVP에서는 분석 도구와 운영 시트를 연결하고, 반복 업무가 확인된 뒤 전용 관리 기능을 만듭니다.

## 7. 신뢰와 정책 원칙

- 유료 참여 여부와 기업 추천 순위를 혼동시키지 않습니다.
- 사례의 고객명, 성과 수치, 로고는 사용 권한을 확인합니다.
- 상담 정보는 명시한 목적과 기간 안에서만 보관합니다.
- 공급 기업 선정 및 제외 기준을 내부 운영 문서로 남깁니다.
- 성과 수치는 `문의`, `유효 리드`, `매칭`, `계약`을 구분해 보고합니다.

## 8. 90일 검증 로드맵

### 1~30일: 문제와 메시지

- 수요 기업 인터뷰 5건 이상
- 공급 기업 인터뷰 5건 이상
- 핵심 사례 3건의 사용 권한과 근거 확보
- 메시지와 CTA 문구 검증

### 31~60일: MVP와 운영

- 랜딩 MVP 공개
- 상담 처리 기준과 담당자 확정
- 이벤트 및 운영 퍼널 측정
- 첫 유효 상담 데이터 수집

### 61~90일: 채널과 BM

- 채널별 유효 리드 비용 비교
- 공급 기업의 리드 품질 평가
- `BM-002` 또는 `BM-003` 가격 인터뷰
- 다음 분기 투자 또는 중단 기준 결정

## 9. Go / Pivot / Stop 기준

| 판단 | 기준 예시 |
|---|---|
| Go | 반복 유입 채널과 유효 매칭이 확인되고 공급자의 재참여 의사가 있음 |
| Pivot | 문의는 발생하지만 대상·메시지·매칭 품질 중 한 축이 지속적으로 낮음 |
| Stop | 인터뷰와 캠페인 후에도 문제 강도와 지불 의사가 확인되지 않음 |
