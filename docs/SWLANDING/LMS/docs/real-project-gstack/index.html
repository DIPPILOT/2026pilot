SLIDE 02 01 / ORIENTATION
02 / 16

오늘 배우는 것은 명령어보다 작업 방식입니다.

AI에게 바로 “만들어 줘”라고 지시하면 그럴듯하지만 검증되지 않은 코드가 쌓입니다. gstack은 3가지 원칙으로 프로젝트를 통제합니다.

01

바로 만들지 않기

코드를 작성하기 전에 사용자 문제와 프로젝트 범위를 먼저 확인하고, 구현 전에 숨겨진 가정을 수면 위로 드러냅니다.

핵심 질문: “누구의 어떤 불편을 해결하는가?”
02

역할을 분리하기

제품(CEO), 디자인(Design), 기술(ENG), 코드 리뷰(Review), 품질 검증(QA) 관점을 한 번에 섞지 않고 각각 다른 스킬로 분리 실행합니다.

기획 단계에서는 코드 수정을 엄격히 금지합니다.
03

결과를 검증하기

AI의 출력은 정답지가 아닙니다. 실제 생성된 파일, git status, git diff, 그리고 브라우저 실행 결과로 사람이 직접 확인합니다.

근거(파일·재현 절차) 없는 통과는 인정하지 않습니다.

SLIDE 04 03 / WINDOWS · START FROM ZERO (PART 1)
04 / 16

처음 설치하는 학습자를 위한 Windows 네이티브 과정 ①

Windows 학습자는 먼저 추가 운영체제 없이 PowerShell에서 바로 설치하는 PATH A (Windows 네이티브)를 따라 합니다.

터미널

컴퓨터에 글자로 명령을 전달하는 창입니다.

PowerShell

Windows에 기본 포함된 터미널입니다.

명령어

복사 후 붙여넣고 Enter를 누릅니다.

WSL

Windows 안의 Ubuntu Linux 선택 기능입니다.

Step 1~3. PowerShell · Git · Node.js · Bun 설치

Windows 키 → PowerShell 실행 후 아래 명령을 순서대로 실행합니다.

winget install --id Git.Git -e winget install OpenJS.NodeJS.LTS
powershell -c "irm bun.sh/install.ps1|iex"
설치 후 PowerShell을 닫고 새로 연 뒤 bun --version 숫자를 확인합니다.

Step 4~6. Codex · Claude Code 설치 및 버전 확인

powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex" winget install Anthropic.ClaudeCode
git --version node --version bun --version codex --version claude --version
각 줄에 버전 번호가 표시되면 기본 도구 준비 완료입니다.
SLIDE 05 03 / WINDOWS · GSTACK LINK & WSL2 / TROUBLESHOOTING
05 / 16

Windows gstack 등록 및 WSL2 선택 과정 · 오류 해결

PATH A (Step 7~10). Windows 네이티브 gstack 등록 & 실습 시작

git clone --single-branch --depth 1 https://github.com/garrytan/gstack.git "$HOME\gstack" cd "$HOME\gstack" .\setup.ps1 --host codex .\setup.ps1 --host claude .\setup.ps1 --status

압축을 푼 실습 project 폴더에서 로컬 Git 기준점을 만든 뒤 시작합니다:

git init git add . git commit -m "실습 시작 상태" codex # 또는 claude

PATH B (선택). WSL2 Ubuntu 설치 요약

Linux 환경 통일이 필요할 때만 사용합니다. Codex·Claude·gstack을 모두 같은 환경(WSL 안)에 설치해야 합니다.

# 관리자 PowerShell에서 WSL 설치 후 재부팅 wsl --install
# Ubuntu 터미널 내부에서 실행 sudo apt update && sudo apt install -y git curl unzip curl -fsSL https://bun.com/install | bash && source ~/.bashrc curl -fsSL https://chatgpt.com/codex/install.sh | sh curl -fsSL https://claude.ai/install.sh | bash git clone --single-branch --depth 1 https://github.com/garrytan/gstack.git ~/gstack cd ~/gstack && ./setup --host codex && ./setup --host claude && ./setup --status

setup.ps1 실행 차단 시

powershell -ExecutionPolicy Bypass -File .\setup.ps1 --host codex 실행

Git 커밋 이름 오류 시

git config user.name "student" 및 이메일 설정 후 재시도

스킬이 안 보일 때

Codex/Claude 종료 후 새 터미널 세션을 열고 --status 재확인

SLIDE 07 METHOD B · PROMPT-DRIVEN SETUP

PROMPT 01 · 읽기 전용 점검

1차: 설치하지 말고 환경만 점검

gstack 설치를 준비하고 있어. 먼저 현재 운영체제와 셸을 확인하고, Git, Bun, Codex 버전과 기존 gstack 설치 여부를 점검해 줘. 아직 설치하거나 파일을 수정하지 말고, 확인한 사실, 부족한 항목, 사용할 설치 경로와 실행할 명령 계획만 보여 줘.
운영체제, 부족한 도구, 설치 경로 계획을 먼저 눈으로 확인합니다.
PROMPT 02 · 승인하며 설치

2차: 조건부 안전 설치 실행

방금 점검한 결과를 기준으로 gstack을 Codex host에 설치해 줘. 조건: 1. https://github.com/garrytan/gstack 공식 저장소만 사용해. 2. Windows 네이티브면 $HOME\gstack과 setup.ps1을 사용하고, macOS·Linux·WSL이면 ~/gstack과 ./setup을 사용해. 3. 기존 gstack 폴더가 있으면 덮어쓰거나 삭제하지 말고 멈춰서 알려 줘. 4. 파괴적인 명령은 실행하지 마. 5. 네트워크 접근이나 홈 폴더 쓰기가 필요하면 먼저 승인을 요청해. 6. 설치 후 --host codex 등록과 --status 확인까지 실행해. 7. 마지막에 실행한 명령, 설치 경로, 상태 결과를 요약해.
PROMPT 03 · 새 세션 첫 실행
