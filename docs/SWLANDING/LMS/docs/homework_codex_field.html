코덱스 현업 과제 10

실제 조직에서 반복되는 업무를 Codex와 연결 앱으로 해결하는 PBL 과제입니다. 각 미션은 상황 파악 → 안전한 자동화 설계 → 실행 → 사람의 승인 → 증거 제출 순서로 진행합니다. 결과만 만드는 것이 아니라, AI가 틀리거나 권한을 넘는 순간을 발견하고 통제하는 과정까지 평가합니다.

10개 미션기획·개발·운영 실무 자동화
60~120분미션별 권장 수행 시간
2~4개 앱미션별 Codex 연동 도구
증거 기반 제출실행 로그·링크·판단 기록

과제 진행 순서

  1. 카드의 과제 상세 보기에서 페르소나와 업무 상황을 읽습니다.
  2. 필요한 앱을 연결하고, 실습용 프로젝트·채널·문서만 사용합니다.
  3. 제공 프롬프트를 복사한 뒤 본인 데이터와 승인 조건을 추가합니다.
  4. Codex의 제안을 검토하고, 쓰기 작업은 미리보기 후 직접 승인합니다.
  5. 지정 산출물과 codex_review.md를 함께 제출합니다.

실행 전 안전 원칙

실제 고객·운영 데이터로 바로 실행하지 마세요. 삭제, 배포, 메일 발송, 티켓 생성처럼 외부 상태를 바꾸는 작업은 반드시 대상과 변경 내용을 미리 확인합니다. 연결되지 않은 앱은 먼저 플러그인 연결을 완료해야 합니다.
