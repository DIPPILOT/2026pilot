# PC 관리자 화면 구성

## 화면 설계 원칙

- PC 가로 화면을 기준으로 좌측 메뉴, 상단 상태 영역, 본문 작업 영역을 구성합니다.
- 대시보드에서 현재 주문과 즉시 조치가 필요한 항목을 먼저 보여 줍니다.
- 주문 목록과 상세 내용을 같은 화면에서 확인할 수 있게 합니다.
- 상태 변경, 품절 처리, 주문 중지는 확인 절차와 변경 이력을 남깁니다.
- 새 주문과 오류는 색상뿐 아니라 소리, 아이콘, 문구로 함께 알립니다.

## 공통 레이아웃

### 좌측 메뉴

- 대시보드
- 주문 관리
- 메뉴 관리
- 품절 관리
- 매출 조회
- 매장 설정
- 사용자 및 권한

### 상단 영역

- 현재 매장
- 주문 접수 상태: 접수 중 또는 일시 중지
- 새 주문 알림
- 관리자 계정
- 현재 시각과 마지막 데이터 갱신 시각

## 1. 로그인 화면

### 확인 내용

- 관리자 아이디
- 비밀번호
- 로그인 실패 사유
- 비밀번호 재설정 진입
- 일정 횟수 이상 실패 시 계정 보호 안내

## 2. 대시보드

### 실시간 주문 현황

- 새 주문 건수
- 접수 대기 건수
- 준비 중 건수
- 준비 완료 건수
- 취소 또는 결제 오류 건수
- 가장 오래 대기 중인 주문과 대기 시간

### 즉시 확인할 알림

- 접수되지 않은 신규 주문
- 기준 시간을 초과한 주문
- 품절 임박 또는 품절 메뉴
- 결제 결과 확인이 필요한 주문
- 시스템 또는 주문 연동 오류
- 모바일 주문 접수 중지 상태

### 당일 판매 요약

- 총 주문 건수
- 결제 완료 금액
- 취소 및 환불 금액
- 평균 주문 금액
- 인기 메뉴와 판매 수량
- 시간대별 주문 추이

### 주요 동작

- 주문 상세 열기
- 주문 상태 빠르게 변경
- 메뉴 품절 처리
- 모바일 주문 접수 일시 중지 및 재개

## 3. 주문 관리 화면

### 목록에서 확인할 내용

- 주문번호
- 주문 시각
- 경과 시간
- 주문 방식: 매장 식사 또는 포장
- 주문 상품 요약
- 총 결제 금액
- 결제 상태
- 주문 상태
- 고객 요청사항 유무

### 검색 및 필터

- 주문번호 검색
- 주문일 범위
- 주문 상태
- 결제 상태
- 주문 방식
- 취소 포함 여부

### 주문 상세에서 확인할 내용

- 상품별 옵션과 수량
- 제외 및 추가 재료
- 고객 요청사항
- 결제 수단과 결제 시각
- 주문 상태 변경 이력
- 관리자 처리 이력
- 취소 사유와 환불 상태

### 주요 동작

- 주문 접수
- 준비 중, 준비 완료, 수령 완료로 상태 변경
- 주문 취소 요청 처리
- 영수증 재출력 또는 주문 내역 출력
- 변경 이력 확인

## 4. 메뉴 관리 화면

### 목록에서 확인할 내용

- 메뉴 이미지와 이름
- 카테고리
- 기본 가격
- 판매 여부
- 품절 여부
- 노출 순서
- 마지막 수정자와 수정 시각

### 편집할 내용

- 메뉴명, 설명, 이미지
- 카테고리와 기본 가격
- 옵션 그룹과 선택 규칙
- 옵션별 추가 금액
- 알레르기 및 원재료 안내
- 판매 시간
- 모바일 화면 노출 여부와 순서

### 저장 전 확인

- 필수 정보 누락
- 중복되거나 유효하지 않은 옵션
- 음수 가격 또는 잘못된 추가 금액
- 현재 주문에 영향을 줄 수 있는 변경

## 5. 품절 관리 화면

### 확인 내용

- 전체 메뉴의 판매 및 품절 상태
- 품절된 시각과 처리자
- 품절 사유
- 자동 판매 재개 예정 시각
- 특정 옵션 또는 재료만 품절인지 여부

### 주요 동작

- 메뉴 즉시 품절 및 해제
- 옵션 또는 재료 단위 품절
- 판매 재개 시간 예약
- 여러 메뉴 일괄 상태 변경

## 6. 매출 조회 화면

### 확인 내용

- 일별, 주별, 월별 매출
- 주문 건수와 평균 주문 금액
- 메뉴별 판매 수량과 매출
- 취소 및 환불 내역
- 결제 수단별 금액
- 시간대별 판매 추이

### 주요 동작

- 기간과 메뉴 기준 필터
- 조회 결과 다운로드
- 마감 데이터 확인

## 7. 매장 설정 화면

### 확인 및 설정 내용

- 매장명과 연락처
- 영업시간과 주문 가능 시간
- 매장 식사 및 포장 제공 여부
- 예상 준비 시간 기본값
- 주문 접수 일시 중지 안내 문구
- 결제 수단 설정
- 영수증 설정
- 관리자 알림 설정

## 8. 사용자 및 권한 화면

### 확인 내용

- 관리자와 직원 계정 목록
- 역할과 접근 권한
- 마지막 로그인 시각
- 계정 활성 상태
- 메뉴, 주문, 설정 변경 이력

### 권한 예시

- 직원: 주문 조회 및 상태 변경
- 매니저: 주문 취소, 품절 및 메뉴 수정
- 관리자: 매장 설정, 계정 및 권한 관리

## 공통 상태 및 예외 처리

- 데이터 로딩 중에는 마지막 갱신 시각과 로딩 상태를 표시합니다.
- 연결이 끊기면 상태 변경 버튼을 막고 재연결 방법을 안내합니다.
- 같은 주문을 여러 관리자가 수정하면 최신 상태를 다시 확인하게 합니다.
- 저장 실패 시 입력값을 유지하고 실패 사유를 표시합니다.
- 위험한 변경은 대상과 영향을 다시 확인한 뒤 실행합니다.

## 추후 결정 사항

- 주문 알림음과 반복 주기
- 주방 전용 주문 화면 필요 여부
- 취소 및 환불 승인 권한
- 매출 데이터 보관 기간
- 외부 POS 및 결제사 연동 범위
