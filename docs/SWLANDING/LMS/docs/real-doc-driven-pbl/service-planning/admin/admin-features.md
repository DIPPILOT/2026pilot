# 관리자 기능

## 대시보드

- 현재 주문 현황 조회
- 주문 상태별 건수 확인
- 당일 판매 요약 확인

## 주문 관리

- 신규 주문 확인
- 주문 상세 내용 조회
- 주문 상태 변경
- 취소 주문 확인

## 메뉴 관리

- 샌드위치와 음료 등록
- 메뉴 이름, 설명, 이미지, 가격 수정
- 판매 여부 설정
- 메뉴 노출 순서 변경
- 옵션과 추가 금액 관리

## 품절 관리

- 메뉴별 품절 상태 설정 및 해제
- 품절 메뉴의 고객 화면 노출 방식 관리

## 매장 설정

- 매장명과 운영 정보 관리
- 주문 가능 시간 설정
- 추후 결제 및 영수증 설정 추가
