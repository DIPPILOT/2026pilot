# 관리자 화면

## 목적

매장 관리자가 메뉴 상태와 고객 주문을 효율적으로 관리할 수 있도록 합니다.

## 이용 환경

- PC 웹 화면을 기본으로 합니다.
- 1280px 이상의 가로 화면에서 주문 목록과 상세 정보를 함께 확인할 수 있게 구성합니다.
- 주문 접수와 상태 변경처럼 자주 사용하는 기능은 최소한의 클릭으로 처리합니다.

## 주요 화면

1. 관리자 로그인 화면
2. 대시보드
3. 주문 관리 화면
4. 메뉴 관리 화면
5. 품절 관리 화면
6. 매장 설정 화면

## 기본 사용자

- 매장 관리자
- 매장 직원

## 권한 원칙

- 관리자 화면은 인증된 사용자만 접근할 수 있습니다.
- 역할에 따른 상세 권한은 추후 정의합니다.
