# 고객 주문 서비스

## 목적

고객이 자신의 휴대전화에서 샌드위치와 음료를 쉽고 빠르게 선택하고 주문할 수 있도록 합니다.

## 이용 환경

- 모바일 웹을 기본으로 합니다.
- 고객은 매장 QR 코드 또는 주문 링크로 접속합니다.
- 세로 화면을 우선 지원하며, 한 손으로 주요 동작을 수행할 수 있게 구성합니다.

## 주요 화면

1. 시작 화면
2. 메뉴 선택 화면
3. 옵션 선택 화면
4. 장바구니 화면
5. 주문 확인 화면
6. 결제 화면
7. 주문 완료 화면
8. 주문 상태 화면

## 주요 기능

- 샌드위치와 음료 카테고리 조회
- 메뉴 상세 정보와 가격 확인
- 샌드위치 옵션 선택
- 음료 옵션 선택
- 수량 변경 및 장바구니 관리
- 주문 내용과 최종 금액 확인
- 결제 진행
- 주문번호와 완료 안내 표시

## 기본 사용자

- 비회원 매장 방문 고객
