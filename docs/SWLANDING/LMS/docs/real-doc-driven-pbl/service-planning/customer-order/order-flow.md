# 고객 주문 흐름

## 기본 흐름

1. 고객이 매장 QR 코드 또는 주문 링크로 모바일 주문 화면에 접속합니다.
2. 샌드위치 또는 음료 카테고리를 선택합니다.
3. 메뉴와 필요한 옵션을 선택합니다.
4. 선택한 상품을 장바구니에 담습니다.
5. 장바구니에서 상품, 옵션, 수량, 금액을 확인합니다.
6. 주문 내용을 최종 확인합니다.
7. 결제 수단을 선택하고 결제를 진행합니다.
8. 결제가 성공하면 주문번호와 예상 준비 상태를 안내합니다.
9. 고객이 주문 상태 화면에서 준비 진행 상황을 확인합니다.

## 예외 흐름

- 품절 메뉴는 선택할 수 없습니다.
- 필수 옵션을 선택하지 않으면 장바구니에 담을 수 없습니다.
- 결제 실패 시 실패 사유와 재시도 방법을 안내합니다.
- 주문 링크가 유효하지 않거나 매장이 주문을 받지 않는 경우 사유와 이용 가능 시간을 안내합니다.
- 네트워크 연결이 끊기면 작성 중인 주문을 가능한 범위에서 유지하고 재시도 방법을 안내합니다.

## 추후 결정 사항

- 지원할 결제 수단
- 주문 취소 가능 시점
- 영수증 출력 여부
- 다국어 및 접근성 지원 범위
