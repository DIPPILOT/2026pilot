# 샌드위치·음료 주문 키오스크 서비스 구현 (`service-implementation`)

`service-planning` 폴더의 기획서(고객 모바일 주문 화면 8종, PC 관리자 화면 8종, 메뉴·주문 공통 정책)를 기반으로 구현된 웹 애플리케이션입니다. 별도의 빌드 과정이나 외부 패키지 설치 없이 브라우저에서 즉시 실행되며, `LocalStorage`와 `BroadcastChannel`을 통해 고객 화면과 관리자 화면이 실시간으로 연동됩니다.

## 폴더 구조

```text
service-implementation/
├── index.html          # 통합 런처 & 실시간 양방향 분할 뷰 (고객 모바일 + PC 관리자 동시 확인)
├── README.md           # 구현 안내 문서
├── shared/
│   ├── menu-data.js    # Google Sheets에서 검증·동기화한 메뉴 데이터 스냅샷
│   └── store.js        # 공통 데이터 스토어, 금액 계산·장바구니 검증 로직, 실시간 양방향 동기화 엔진
├── customer/
│   ├── index.html      # 고객 모바일 주문 서비스 마크업
│   ├── styles.css      # 모바일 세로 화면(360px+) 및 엄지 영역 최적화 스타일시트
│   └── app.js          # 고객 주문 8개 화면 및 예외 처리 로직
└── admin/
    ├── index.html      # PC 관리자 센터 마크업
    ├── styles.css      # PC 가로 화면(1280px+) 좌측 메뉴 + 상단 바 + 분할 작업 영역 스타일시트
    └── app.js          # 관리자 8개 화면, 역할별 권한, 알림음 및 감사 로그(Audit Log) 로직
```

## 메뉴 데이터 원본

- Google Sheets: `샌드위치가게메뉴`의 `시트1!A1:R12`
- 브라우저에서 인증이 필요한 시트를 직접 호출하지 않고, 검증된 값을 `shared/menu-data.js`로 동기화합니다.
- 메뉴 ID, 카테고리, 가격, 배지, 추천·판매·품절 상태, 알레르기, 원산지, 판매 시간, 표시 순서를 시트에서 관리합니다.

## 실행 방법

1. 브라우저에서 `service-implementation/index.html` 파일을 바로 열거나, 로컬 정적 서버로 실행합니다:
   ```bash
   npx serve /Users/hojunlee/workspace/test_26_dip/service-implementation
   ```
2. **통합 분할 뷰 (`index.html`)**에서는 좌측의 **고객 모바일 주문 화면**과 우측의 **PC 관리자 화면**을 한눈에 보면서 실시간 연동을 테스트할 수 있습니다.
3. 개별 화면만 단독으로 열려면 아래 파일을 실행하세요:
   - 고객 모바일 주문 화면: `customer/index.html`
   - PC 관리자 화면: `admin/index.html`

## 기획서 대비 주요 구현 사항

### 1. 고객 모바일 주문 서비스 (`customer/`)
- **공통 레이아웃 및 접근성**:
  - 상단 영역(매장명, 현재 화면 제목, 이전 버튼, 장바구니 수량 배지, 진행 중인 주문 바로가기) 및 하단 고정 엄지 영역(현재 금액, 주 동작 버튼, 비활성화 사유 안내) 제공
  - 품절·필수 선택·오류 상태를 색상뿐 아니라 아이콘(`🚫`, `⚠️`, `✔️`)과 문구로 함께 표시
- **8개 화면 전체 구현**:
  1. **접속 및 주문 시작 화면**: 매장 정보, 주문 가능 시간, 예상 준비 시간, 매장 식사/포장 선택, 예외 상태(영업시간 종료, 일시적 주문 중지, 유효하지 않은 매장 링크, 네트워크 연결 끊김) 안내
  2. **메뉴 목록 화면**: 추천/샌드위치/음료 탭, 인기·신메뉴 배지, 품절 표시 및 선택 제한
  3. **메뉴 상세 및 옵션 선택 화면**: 알레르기·원산지 안내, 샌드위치 옵션(빵 종류, 사이즈, 세트, 추가/제외 재료) 및 음료 옵션(사이즈, 온도, 얼음 양, 당도), 필수 미선택 시 담기 제한 및 사유 표시, 최대 선택 개수 초과 시 초점 이동 및 수정 방법 안내
  4. **장바구니 화면**: 옵션 수정 및 삭제, 담은 뒤 품절되거나 가격이 변경된 상품 실시간 감지 및 동기화
  5. **주문 확인 화면**: 매장 오선택 방지 강조, 요청사항 입력 및 알레르기 대응 불가 안내
  6. **결제 화면**: 지원 결제 수단 선택, 중복 결제 방지(결제 처리 중 버튼 잠금), 결제 상태 5종(대기, 처리 중, 성공, 실패 및 재시도, 결제 결과 확인 중) 지원
  7. **주문 완료 화면**: 대형 주문번호, 주문 요약, 예상 준비 시간, 매장 문의 안내
  8. **주문 상태 화면**: 결제 완료 → 접수 → 준비 중 → 준비 완료 단계별 실시간 진행 표시 및 취소 시 사유·환불 안내

### 2. PC 관리자 화면 (`admin/`)
- **8개 화면 전체 구현**:
  1. **로그인 화면**: 아이디/비밀번호 인증, 실패 사유 표시, 5회 실패 시 계정 보호 잠금 안내, 역할별(점장/매니저/직원) 원클릭 데모 로그인
  2. **대시보드**: 상태별 실시간 건수, 최장 대기 주문, 즉시 확인 알림, 당일 판매 요약 및 시간대별 주문 추이(시각 차트 + 접근성 데이터 테이블), 빠른 상태 변경 및 품절 토글
  3. **주문 관리 화면**: 좌측 주문 목록 + 우측 상세 분할 레이아웃, 다중 검색·필터, 제외/추가 재료 강조, 상태 변경, 주문 취소 및 환불 모달, 영수증/주문서 출력 모달
  4. **메뉴 관리 화면**: 메뉴 등록·수정, 노출 순서 조정, 저장 전 필수값·중복·음수 가격 검증
  5. **품절 관리 화면**: 메뉴 즉시 품절/해제, 일괄 상태 변경, 자동 판매 재개 예정 시각 설정, 세부 옵션·재료 단위 품절 토글, 품절 메뉴 고객 노출 방식 설정
  6. **매출 조회 화면**: 일별/주별/월별 매출, 메뉴별·결제수단별 집계, CSV 다운로드, 마감 정산 확인
  7. **매장 설정 화면**: 운영/주문 가능 시간, 식사 방식 허용, 예상 준비 시간, 일시 중지 문구, 결제 수단, 영수증 및 알림음 설정
  8. **사용자 및 권한 화면**: 직원/매니저/점장 권한 체계 적용 및 전체 변경 이력(Audit Log) 조회
