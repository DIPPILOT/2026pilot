# 서비스 분석 정책

이 폴더는 고객 주문과 관리자 운영 데이터를 어떤 기준으로 수집·해석할지 정의하고, 분석용 API를 설계하기 위한 문서를 보관합니다.

## 목적

- 서비스 성과를 판단할 공통 지표를 정의합니다.
- 고객 행동과 주문 흐름의 분석 기준을 통일합니다.
- 메뉴, 매출, 품절, 운영 효율 분석을 지원합니다.
- 화면·기능별 이벤트 수집 규칙을 관리합니다.
- 분석 API의 요청, 응답, 권한, 오류 규칙을 설계합니다.
- 개인정보와 결제정보를 불필요하게 수집하지 않도록 제한합니다.

## 문서 작성 원칙

- 모든 지표에는 목적, 계산식, 집계 단위, 필터, 제외 조건을 명시합니다.
- 모든 이벤트에는 발생 조건과 필수 속성을 명시합니다.
- 화면에 표시되는 숫자와 API가 반환하는 숫자는 같은 계산 정의를 사용합니다.
- 지표 이름만으로 의미가 불분명하면 사용 예시를 함께 기록합니다.
- 분석을 위해서라도 비밀번호, 카드번호, 결제 토큰은 수집하지 않습니다.
- 정의가 변경되면 변경일과 영향을 받는 지표·API를 기록합니다.
