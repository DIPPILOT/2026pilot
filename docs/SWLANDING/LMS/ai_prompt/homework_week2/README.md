학생 배포용 개인 과제다. 하루 2개, 총 10개이며 각 과제 50점, 하루 100점이다. 2주 성적은 5일 점수의 평균으로 산출한다. 권장 소요 시간은 하루 90~120분이다. 수업 실습 시간과 별도이며 실제 마감 시각과 제출 채널은 강사가 공지한다.

## 제출 규칙

각 Day를 학번_이름_DayNN.zip으로 제출한다. 내부에 HW-DNN-01, HW-DNN-02 폴더를 만들고 각 문제의 지정 소스코드, 설계문서와 ai_review.md를 넣는다. 도식은 Mermaid 원문 또는 이미지와 설명을 제출한다. 실행 가능한 코드 파일(.js, .py, .html 등)을 포함하여 동작 검증이 가능하도록 한다.

각 ai_review.md에는 사용 도구, 직접 작성한 질문, 핵심 응답, 자신의 최종 판단과 확인 근거를 남긴다. AI 의견을 억지로 거절할 필요는 없으며 수용할 때에도 기술적 근거를 설명한다. 도구 접근이 안 되면 작성한 검토 질문과 자기 검토 결과를 내고 접근 불가를 명시한다. 해당 항목은 검토 질문과 판단 증거로 평가한다.

이 과제는 해결 절차와 모범 답안을 제공하지 않는다. 학생은 문제에 맞는 구조와 정책을 선택하고 검증해야 한다. 코드만 제출하거나 AI 대화만 제출하면 해당 산출물·판단 항목의 점수를 받을 수 없다. 특정 언어·프레임워크·유료 도구 사용은 평가하지 않는다.

## 프로젝트와 연계

공통 배경은 Video & Advertising Platform (VidAce)이다. 1주차의 요구사항, 데이터 모델, API 계약을 이어받아 2주차에는 실전 구현, 보안 감사, 멱등 결제, 회복 탄력성(Resilience) 아키텍처로 확장한다.
