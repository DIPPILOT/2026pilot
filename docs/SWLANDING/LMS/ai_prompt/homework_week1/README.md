# 1주차 숙제 — Day 1~5

학생 배포용 개인 과제다. 하루 2개, 총 10개이며 각 과제 50점, 하루 100점이다. 1주 성적은 5일 점수의 평균으로 산출한다. 권장 소요 시간은 하루 90~120분이다. 수업 실습 시간과 별도이며 실제 마감 시각과 제출 채널은 강사가 공지한다.

## 일차별 과제

- [Day 1: 요구사항과 Domain 책임](day1_homework_mission.md) — 서로 충돌하는 서비스 요구를 결정하라 / 조회수와 광고 비용은 누구 책임인가
- [Day 2: Flow와 설계 변경](day2_homework_mission.md) — 광고 서버가 멈춰도 재생 경험을 설명하라 / 정책 변경으로 깨진 문서를 찾아라
- [Day 3: 데이터 모델과 무결성](day3_homework_mission.md) — 조회·노출·청구를 구별하는 데이터 모델을 설계하라 / 광고 삭제 요청과 과거 청구의 충돌을 해결하라
- [Day 4: API 계약과 검토](day4_homework_mission.md) — 다른 팀이 구현할 수 있는 API 계약을 제출하라 / 깨진 계약의 호환성을 회복하라
- [Day 5: UI/UX와 사용자 검증](day5_homework_mission.md) — 처음 광고를 만드는 사용자의 화면을 설계하라 / 자신의 화면을 반박하고 개선하라

## 제출 규칙

각 Day를 학번_이름_DayNN.zip으로 제출한다. 내부에 HW-DNN-01, HW-DNN-02 폴더를 만들고 각 문제의 지정 파일과 ai_review.md를 넣는다. 도식은 Mermaid 원문 또는 이미지와 설명을 제출한다. 외부 디자인 링크를 사용하는 경우에도 검토 가능한 이미지 사본을 포함한다. UI 구현을 선택했다면 실행 방법을 함께 쓴다.

각 ai_review.md에는 사용 도구, 직접 작성한 질문, 핵심 응답, 자신의 최종 판단과 확인 근거를 남긴다. AI 의견을 억지로 거절할 필요는 없으며 수용할 때에도 근거를 설명한다. 도구 접근이 안 되면 작성한 검토 질문과 자기 검토 결과를 내고 접근 불가를 명시한다. 해당 항목은 검토 질문과 판단 증거로 평가한다.

이 과제는 해결 절차와 모범 답안을 제공하지 않는다. 학생은 문제에 맞는 구조와 정책을 선택하고 검증해야 한다. 화면만 제출하거나 AI 대화만 제출하면 해당 산출물·판단 항목의 점수를 받을 수 없다. 특정 언어·프레임워크·유료 도구 사용은 평가하지 않는다.

## 프로젝트와 연계

공통 배경은 Video & Advertising Platform이다. Day 1 요구사항·책임 → Day 2 흐름 → Day 3 데이터 → Day 4 API → Day 5 화면으로 연결한다. 이전 답안의 오류를 고칠 수 있으나 변경 이유를 기록한다. 이전 제출이 미완료여도 각 문제에 제공된 상황으로 독립 수행하고 필요한 가정을 명시할 수 있다. Day 5 숙제 2는 숙제 1 산출물을 사용한다.

Skill 코드는 교육 역량 표시이며 실행 도구의 Skill을 뜻하지 않는다. 코드 정의는 [Skill 분류](../skill_tasks/README.md)를 참고한다. 기존 Mission·Summation·LMS 웹과 별도로 관리하는 숙제 문서이며 현재 범위는 첫 주 Day 1~5다.
