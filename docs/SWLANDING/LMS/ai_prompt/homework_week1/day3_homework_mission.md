## HW-D03-01 — 조회·노출·청구를 구별하는 데이터 모델을 설계하라

- 영역: HYBRID
- 기술 Skill: TECH-DATA, TECH-DDD
- AI Skill: AI-CTX, AI-REV, AI-DOC
- 예상 시간: 45~60분

### 문제 상황

하나의 Campaign에는 여러 광고 소재가 있고 영상에는 여러 Tag가 있다. 동일 광고 이벤트가 재전송될 수 있다. Campaign 예산이 바뀌어도 과거 청구 금액은 보존되어야 한다.

### 해결해야 할 문제

6개 이상 Entity로 ERD를 설계하라. PK·FK·Cardinality·필수값·Unique 조건과 Domain 소유자를 명시하라. 다대다 관계와 이력 보존을 설명하고 샘플 레코드 8개 이상으로 관계 및 중복 이벤트 판정을 보여라. SQL 실행은 선택이다.

정책에 여러 답이 가능하다. 선택한 답의 근거와 제외한 대안을 최소 1개 설명하라. 문제에 없는 정보는 가정으로 표시하라.

### 제출물

data_model.md: ERD, 데이터 사전, 샘플 레코드, 제약 및 정규화 근거.

본인이 사용한 AI 질문, 핵심 응답, 수용·수정·거절 판단을 과제 폴더의 ai_review.md에 제출하라. AI 검토를 위해 완성된 답을 외우거나 제공된 프롬프트를 복사하는 대신 자신의 검토 질문을 작성한다.

### 평가 기준 — 50점

관계·제약 정확성 20점; 중복·이력 보존 설계 15점; 샘플 일관성 10점; AI 검토와 자기 판단의 증거 5점. 각 항목은 제출된 증거의 완전성과 일관성에 따라 부분 점수를 부여한다.

### 제출 전 자기 점검

- 요구한 개수와 파일을 충족했는가?
- 결과를 직접 설명할 수 있으며 선택의 근거가 있는가?
- 도식·예시·문서가 서로 같은 정책을 표현하는가?

## HW-D03-02 — 광고 삭제 요청과 과거 청구의 충돌을 해결하라

- 영역: HYBRID
- 기술 Skill: TECH-DATA, TECH-QA
- AI Skill: AI-CTX, AI-REV, AI-DOC
- 예상 시간: 45~60분

### 문제 상황

현재 모델은 Campaign 삭제 시 소재·노출·청구를 모두 연쇄 삭제한다. 광고주는 노출을 즉시 중단해 달라고 요청했고, 운영자는 지난 청구 내역을 계속 확인해야 한다. 이는 과제용 업무 요구이며 법적 보존기간은 정해지지 않았다.

### 해결해야 할 문제

현 모델의 문제 3개 이상과 수정안을 작성하라. 삭제·중단·비식별화 등 선택한 정책의 적용 범위를 구분하고 데이터 변경 전후 예시를 제시하라. 정상·경계·실패 검증 사례 4개 이상과 영향받는 Flow/API를 적어라.

정책에 여러 답이 가능하다. 선택한 답의 근거와 제외한 대안을 최소 1개 설명하라. 문제에 없는 정보는 가정으로 표시하라.

### 제출물
