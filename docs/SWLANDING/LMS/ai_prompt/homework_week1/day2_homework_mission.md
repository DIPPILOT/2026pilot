## HW-D02-01 — 광고 서버가 멈춰도 재생 경험을 설명하라

- 영역: HYBRID
- 기술 Skill: TECH-FLOW, TECH-ARCH
- AI Skill: AI-CTX, AI-REV, AI-DOC
- 예상 시간: 45~60분

### 문제 상황

Viewer가 영상 재생을 요청했다. 광고 서버가 늦게 응답하거나 후보 광고가 없을 수 있고, 사용자가 재생 직전에 화면을 닫을 수도 있다. 서비스는 광고 장애만으로 영상 시청이 무기한 멈추는 것을 원하지 않는다.

### 해결해야 할 문제

정상 User Flow와 Sequence를 작성하고, 지연·후보 없음·화면 이탈 3가지 예외를 표현하라. 대기 한계와 늦은 응답 처리 정책은 스스로 정하고 이유를 쓰라. 각 흐름의 최종 사용자 화면과 기록되는 이벤트를 명시하라.

정책에 여러 답이 가능하다. 선택한 답의 근거와 제외한 대안을 최소 1개 설명하라. 문제에 없는 정보는 가정으로 표시하라.

### 제출물

playback_flow.md: User Flow, Mermaid Sequence, 예외 결과표, 정책 근거.

본인이 사용한 AI 질문, 핵심 응답, 수용·수정·거절 판단을 과제 폴더의 ai_review.md에 제출하라. AI 검토를 위해 완성된 답을 외우거나 제공된 프롬프트를 복사하는 대신 자신의 검토 질문을 작성한다.

### 평가 기준 — 50점

메시지·책임 표현 15점; 세 예외의 완료 상태 20점; 정책 근거 10점; AI 검토와 자기 판단의 증거 5점. 각 항목은 제출된 증거의 완전성과 일관성에 따라 부분 점수를 부여한다.

### 제출 전 자기 점검

- 요구한 개수와 파일을 충족했는가?
- 결과를 직접 설명할 수 있으며 선택의 근거가 있는가?
- 도식·예시·문서가 서로 같은 정책을 표현하는가?

## HW-D02-02 — 정책 변경으로 깨진 문서를 찾아라

- 영역: HYBRID
- 기술 Skill: TECH-FLOW, TECH-BA, TECH-QA
- AI Skill: AI-CTX, AI-REV, AI-DOC
- 예상 시간: 45~60분

### 문제 상황

요구사항 v1은 비회원 시청 허용이다. 변경 요청 v2는 비회원 시청 유지와 ‘동일 로그인 사용자에게 동일 광고는 하루 3회 이하’를 요구한다. 화면 명세는 모든 사용자를 로그인 화면으로 보내고, Sequence는 광고 선택 시마다 노출 횟수를 증가시킨다. 데이터 메모에는 광고별 전체 요청 수만 있다.

### 해결해야 할 문제

불일치·누락 4개 이상을 찾아 원문 근거와 영향 문서를 제시하라. 비회원 처리와 하루의 기준은 미결정 정책으로 식별하고 과제용 가정을 제안하라. 수정된 흐름과 Decision Log를 제출하고, 선택 후 실제 노출되지 않은 사례가 정책에 미치는 영향을 설명하라.

정책에 여러 답이 가능하다. 선택한 답의 근거와 제외한 대안을 최소 1개 설명하라. 문제에 없는 정보는 가정으로 표시하라.

### 제출물

change_review.md: 이슈표, 변경 영향, 수정 흐름, Decision Log.

본인이 사용한 AI 질문, 핵심 응답, 수용·수정·거절 판단을 과제 폴더의 ai_review.md에 제출하라. AI 검토를 위해 완성된 답을 외우거나 제공된 프롬프트를 복사하는 대신 자신의 검토 질문을 작성한다.

### 평가 기준 — 50점

근거 있는 불일치 탐지 20점; 변경 추적 15점; 가정·결정 구분 10점; AI 검토와 자기 판단의 증거 5점. 각 항목은 제출된 증거의 완전성과 일관성에 따라 부분 점수를 부여한다.
