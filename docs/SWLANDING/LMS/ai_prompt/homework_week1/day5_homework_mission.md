개인 제출 / 숙제 2개 / 권장 총 90~120분. 제출 규칙은 [운영 안내](README.md)를 따른다.

학습 근거: [기존 Mission](../day5_codex_mission.md), [Summation](../day5_codex_summation.md), [추가 Skill Task](../skill_tasks/day05_skill_tasks.md).

## HW-D05-01 — 처음 광고를 만드는 사용자의 화면을 설계하라

- 영역: HYBRID
- 기술 Skill: TECH-UX, TECH-FE
- AI Skill: AI-CTX, AI-REV, AI-DOC
- 예상 시간: 45~60분

### 문제 상황

광고 경험이 없는 지역 상인이 모바일로 Campaign을 만들려 한다. 이름·소재·타깃·예산·기간을 입력해야 한다. 제출은 승인 요청이며 실제 광고 시작은 승인 후다. 업로드 실패 때 입력한 값이 사라지면 안 된다.

### 해결해야 할 문제

최소 3개 화면과 화면 간 이동을 설계하라. Loading·Empty·Error·Disabled·Success 상태의 표시 위치와 복구 동작을 제시하라. 승인 요청과 실제 시작의 차이를 문구로 표현하고 API 계약과 화면 요소 4개 이상을 연결하라. 종이 스케치·디자인 도구·HTML 중 자유롭게 선택하라.

정책에 여러 답이 가능하다. 선택한 답의 근거와 제외한 대안을 최소 1개 설명하라. 문제에 없는 정보는 가정으로 표시하라.

### 제출물

ui_design.md 및 화면 이미지 또는 실행 가능한 프로토타입: 화면 흐름, 상태표, API 연결표.

본인이 사용한 AI 질문, 핵심 응답, 수용·수정·거절 판단을 과제 폴더의 ai_review.md에 제출하라. AI 검토를 위해 완성된 답을 외우거나 제공된 프롬프트를 복사하는 대신 자신의 검토 질문을 작성한다.

### 평가 기준 — 50점

흐름·상태·복구 설계 20점; 사용자 관점 문구 15점; API 연결 10점; AI 검토와 자기 판단의 증거 5점. 각 항목은 제출된 증거의 완전성과 일관성에 따라 부분 점수를 부여한다.

### 제출 전 자기 점검

- 요구한 개수와 파일을 충족했는가?
- 결과를 직접 설명할 수 있으며 선택의 근거가 있는가?
- 도식·예시·문서가 서로 같은 정책을 표현하는가?

## HW-D05-02 — 자신의 화면을 반박하고 개선하라

- 영역: HYBRID
- 기술 Skill: TECH-UX, TECH-QA
- AI Skill: AI-CTX, AI-REV, AI-DOC
- 예상 시간: 45~60분

### 문제 상황

광고주가 ‘승인 대기를 광고 시작으로 오해했고, 업로드 재시도 버튼을 찾지 못했으며, 하루 예산과 총예산을 구별하지 못했다’고 말했다. 이는 과제에서 제공한 가상 피드백이다.

### 해결해야 할 문제

숙제 1의 화면을 검토해 세 피드백의 해당 여부를 각각 근거로 판정하라. 본인이 추가 발견한 문제 2개와 함께 우선순위를 정하라. 개선 전후 화면과 관찰 가능한 재검증 기준 3개를 제출하라. AI 검토는 가상 리뷰로 표시하고 실제 사용자 테스트 결과처럼 쓰지 말라.

정책에 여러 답이 가능하다. 선택한 답의 근거와 제외한 대안을 최소 1개 설명하라. 문제에 없는 정보는 가정으로 표시하라.

### 제출물

ux_review.md 및 before/after 이미지: 총 5개 이슈 판정, 우선순위, 개선 증거, 재검증 기준.

본인이 사용한 AI 질문, 핵심 응답, 수용·수정·거절 판단을 과제 폴더의 ai_review.md에 제출하라. AI 검토를 위해 완성된 답을 외우거나 제공된 프롬프트를 복사하는 대신 자신의 검토 질문을 작성한다.

### 평가 기준 — 50점

근거 있는 문제 판단 20점; 개선 전후 증거 15점; 재검증 기준 10점; AI 검토와 자기 판단의 증거 5점. 각 항목은 제출된 증거의 완전성과 일관성에 따라 부분 점수를 부여한다.
